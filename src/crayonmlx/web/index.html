          ИНСТРУМЕНТЫ ВООБРАЖЕНИЯ
          
Модели на вашем Mac

          

            Положите полный checkpoint в папку моделей или скачайте его с
            Hugging Face.
          

        

        

          

            

              
Локальные модели

              
            

            

            

            

              Каждая модель — отдельная папка с конфигурацией, transformer, VAE
              и энкодерами. Поддерживаются полные Diffusers / MFLUX checkpoints
              для FLUX.1 и Qwen Image Edit. Для HF cache выберите папку
              конкретного snapshot.
            

          

          

            
Скачать с Hugging Face

            

              
              
              

                Полный репозиторий будет скачан в папку моделей. Токен для
                закрытых моделей задаётся в настройках. Условия доступа
                принимаются на сайте HF.
              

              
            

            

          

        

      

      

        

          ВАШЕ ПРОСТРАНСТВО
          
Настройки студии

        

        

          
          

            
          

          

            Скачанные и добавленные вручную модели доступны из этой папки.
          

          
          

            
          

          

            Можно выбрать любую доступную папку. Старые записи истории сохраняют
            прежние пути.
          

          
          

          
          

            Токен хранится локально в файле с доступом только вашему
            пользователю и не возвращается в браузер.
          

          

          
          

            По умолчанию 15 минут после окончания последней генерации.
          

          

          
        

        

          
Внутренние данные

          

            Настройки, пресеты, конфиги, история и HF-токен. Модели и
            изображения останутся по прежним путям.
          

          
          

            
          

          

            Перенос в пустую папку применяется после перезапуска. Исходная копия
            сохраняется. После переноса работа приостановится до перезапуска.
